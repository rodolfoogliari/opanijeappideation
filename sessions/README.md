# Sessions — derivation history

**These files are no longer the register of record.**

Under **D83** (Game Addendum 04 §7, 2026-08-03), session prose stopped being where the estate's
numbered items live. The registers in `../registers/` hold the current state of every series. What
lives here is the **reasoning** — the arguments, the rejected alternatives, the derivations, and the
confirm-or-correct sections that produced each ruling.

That reasoning is worth keeping and worth reading. It is not worth *consulting for current status*,
because a status stated in a session document is only true as of that session's date.

**Rule of use.** For *what is true now*, read the registers. For *why it is true*, read these.
Where a session document and a register disagree, **the register governs** — and the disagreement is
a bug in the register worth reporting.
